Netflix Data Cleaning & Preparation Using Python

Project Overview

This project focuses on cleaning and preparing the Netflix dataset for business analytics and reporting.

This project was completed as part of the Auspify – Data Analysis Using Python Internship Program.

Objective

To organize and clean the Netflix dataset by identifying missing values, removing duplicate records, and standardizing data for further analysis.

Tools & Technologies

- Python
- Pandas
- NumPy
- Google Colab / Jupyter Notebook

Tasks Performed

1. Imported the Netflix dataset using Pandas.
2. Identified and handled missing values.
3. Removed duplicate records.
4. Standardized columns such as Country, Rating, and Type.
5. Exported the cleaned dataset for further analysis.

Skills Learned

- Data Cleaning
- Data Preprocessing
- Pandas Fundamentals
- Data Quality Management
- Dataset Preparation

Project Files

- "Netflix_Data_Cleaning.ipynb" – Python notebook
